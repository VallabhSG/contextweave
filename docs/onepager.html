Why now

Bigger context windows don't fix memory — they make it worse. Chroma (2026) found all 18 frontier models degrade as input grows; the lost-in-the-middle effect drops accuracy ~70% → ~55% once ~20 documents fill the window. Coatue calls memory "the new bottleneck"; NVIDIA ships a tiered agent-memory stack; clouds now meter memory.

Market ≈ $6B (2025) → $28B (2030), ~35% CAGR (Mordor; estimates vary — see market memo). Agentic AI ~$52B by 2030.

What we built

  • Hybrid retrieval — vector + full-text + knowledge graph, fused.
  • Intent-aware temporal decay — temporal queries see their history.
  • Cross-encoder reranking — measured recall/MRR lift.
  • Token-budgeted assembly — MMR-dedup + query-aware compression.
  • Honest confidence — calibrated, hedges on weak context.
  • MCP server — private agent memory in one config block.
